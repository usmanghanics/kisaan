# Madadgar Kisan: public pages

Privacy Policy, Terms and Conditions, About and the account deletion page,
in English and Urdu, for Google Play and for links from the app.

Generated by `tool/legal/generate.py` in the app's repository from
`tool/legal/content.py`, which also generates the app's own legal screens.
Edit there and regenerate rather than editing these files.

## Publish on GitHub Pages

1. Create a public repository and upload everything in this folder.
2. Settings, Pages: Source "Deploy from a branch", branch `main`, folder `/ (root)`, Save.
3. After a minute the site is at `https://<user>.github.io/<repository>/`.

## Links for Play Console

- Privacy policy: `<site>/privacy.html`
- Account deletion: `<site>/delete-account.html`
- Urdu version of any page: add `?lang=ur`.
